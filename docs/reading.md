## Go 运行时：从模型到机制 { #go-runtime }

这一组笔记按照「调度 → 内存 → GC → 网络 → 并发」组织。阅读源码时，请留意文章讨论的 Go 版本；运行时实现会随版本演进。

先建立全景，再分别理解 G、M、P 的职责。

[GMP 模型总览](posts/go/00.%20GMP%20模型总览.md) → [Goroutine](posts/go/01.%20Goroutine(G).md) → [Machine](posts/go/02.%20Machine(M).md) → [Processor](posts/go/03.%20Processor(P).md)

### 02 · 一次内存分配经过哪些层？

从堆的组织方式读到每个 P 的本地缓存，理解分层分配如何减少竞争。

[mheap](posts/go/04.%20内存管理--mheap.md) → [mcentral](posts/go/05.%20内存管理--mcentral.md) → [mcache](posts/go/06.%20内存管理--mcache.md)

### 03 · GC 如何兼顾正确性与开销？

先看可达性标记，再看并发写入下的屏障，最后理解回收节奏与目标控制。

[三色标记法](posts/go/07.%20GC--三色标记法.md) → [混合写屏障](posts/go/08.%20GC--混合写屏障.md) → [调度与目标控制](posts/go/09.%20GC--调度与目标控制.md)

### 04 · 网络 I/O 如何与调度器协作？

[I/O 多路复用](posts/go/10.%20网络模型--IO多路复用.md) → [网络模型与 GMP 协作](posts/go/11.%20网络模型--同GMP模型协作.md)

### 05 · 如何组织并发与共享状态？

[Channel](posts/go/12.%20并发同步--channel.md) → [Mutex 与 RWMutex](posts/go/13.%20并发同步--mutex%20&%20rwmutex.md) → [sync.Pool](posts/go/14.%20sync.Pool.md) → [map](posts/go/15.%20map.md) → [errgroup](posts/go/16.%20errgroup.md)
